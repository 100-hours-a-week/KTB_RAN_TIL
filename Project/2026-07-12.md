# 코딩테스트

## 완전 탐색 1

## 1. 자리 수 완전 탐색

### 1. 한 자리 고정 완전탐색 (단순 for 1중)

기준점 하나를 정해서 전체를 한 번씩 순회 → 최적값 갱신

```python
for cur in range(n):
    cost = sum(arr[i] * abs(i - cur) for i in range(n))
    min_val = min(min_val, cost)
```

- 시간복잡도: O(N²)
- **포인트**: "기준을 하나씩 바꿔가며 전체를 다시 계산" 패턴

### 2. 두 자리 조합 완전탐색 (짝 찾기)

인덱스 하나를 고정하고, 그 뒤 범위에서 짝이 되는 대상을 탐색

```python
for i, ch in enumerate(s):
    if ch == "(":
        for j in range(i, len(s)):
            if s[j] == ")":
                cnt += 1
```

- 시간복잡도: O(N²)
- **포인트**: 두 번째 루프가 `range(i, ...)` 또는 `range(i+1, ...)`로 시작 → 순서 있는 쌍(중복 없는 조합)

### 3. 세 자리 조합 완전탐색 (i < j < k)

서로 다른 세 인덱스를 "증가하는 순서"로 고정

```python
for i in range(n):
    for j in range(i+1, n):
        for k in range(j+1, n):
            if arr[i] <= arr[j] <= arr[k]:
                cnt += 1
```

- 시간복잡도: O(N³)
- **포인트**: `i+1`, `j+1`로 시작점을 밀어주는 게 핵심 → 같은 조합 중복 계산 방지

### 4. 격자 - 연속 구간 탐색 (슬라이딩形)

가로/세로로 연속된 K칸을 훑으면서 최적값 계산

```python
for y in range(n):
    for x in range(n - 3 + 1):
        max_cnt = max(max_cnt, grid[y][x] + grid[y][x+1] + grid[y][x+2])
```

- 시간복잡도: O(N²)
- **포인트**: 범위를 벗어나지 않게 `n - k + 1`까지만 x를 움직임 (여기선 k=3)

> 참고로 이 코드에 있는 `in_range` 함수는 정의만 하고 안 쓰고 있어 — 지워도 무방할 듯.

### 5. 격자 - 두 점(경유지) 조합 완전탐색

시작/끝은 고정, 중간 경유지 2곳을 좌표로 조합 탐색 (3번 유형의 격자 버전)

```python
for y1 in range(1, r-1):
    for x1 in range(1, c-1):
        if grid[y1][x1] == grid[0][0]:
            continue
        for y2 in range(y1+1, r-1):
            for x2 in range(x1+1, c-1):
                if grid[y1][x1] == grid[y2][x2]:
                    continue
                if grid[y2][x2] == grid[r-1][c-1]:
                    continue
                answer += 1
```

- 시간복잡도: O(R²C²)
- **포인트**: 3번 유형처럼 "증가하는 순서"로 두 점을 고르는데, 좌표가 2차원이라 `for`가 4중이 됨

## 2. 구간단위 완전 탐색

> **구간의 시작점을 기준으로 탐색
> 시작점 기준 잡기 중요**

### 1. 고정 길이 구간 (길이 K 고정, 시작점만 이동)

**구간의 길이**가 미리 정해져 있고, 시작점만 옮겨가며 탐색

```python
for startIdx in range(n - k + 1):
    total = sum(arr[startIdx:startIdx+k])
    max_sum = max(max_sum, total)
```

- 시간복잡도: O(N·K)
- **포인트**: 구간 길이가 고정이라 `range(n-k+1)`로 시작점 범위만 제한하면 끝

### 2. 배열에 기록 후 고정 길이 구간 탐색

입력을 바로 쓰지 않고, 좌표/위치 기반 데이터를 배열에 매핑한 뒤 1번과 동일한 방식 적용

```python
arr = [0] * (10000 + 1)
for _ in range(n):
    pos, char = input().split()
    arr[int(pos)] = 1 if char == "G" else 2

for startIdx in range(len(arr) - k):
    total = sum(arr[startIdx:startIdx+k+1])
    max_sum = max(max_sum, total)
```

- **포인트**: "위치 → 배열 인덱스"로 변환하는 전처리 단계가 추가된 것 빼면 1번과 동일한 패턴

### 3. 모든 구간 탐색 (시작점 + 끝점 둘 다 완전탐색)

길이가 정해져 있지 않을 때, 가능한 모든 (시작, 끝) 쌍을 완전탐색

```python
for startIdx in range(n):
    for endIdx in range(startIdx+1, n+1):
        total = sum(arr[startIdx:endIdx])
        md = total / (endIdx - startIdx)
        for ele in range(startIdx, endIdx):
            if arr[ele] == md:
                cnt += 1
                break
```

- 시간복잡도: O(N³) (구간 O(N²) × 구간 내부 확인 O(N))
- **포인트**: "구간을 정하는 이중 for" + "그 구간 안에서 조건 확인하는 for"가 합쳐진 형태. `endIdx`는 exclusive로 써서 `arr[startIdx:endIdx]`, `endIdx - startIdx`가 구간 길이가 됨

## 3. 자리마다 숫자를 정하는 완전탐색

공통 포인트

```jsx
for i in range(...):      # 1번째 자리 결정
    for j in range(...):  # 2번째 자리 결정
        for k in range(...):  # 3번째 자리 결정
            # 세 자리가 모두 정해진 상태 → 조건 확인
```

### 1. 자리마다 독립적으로 숫자 정하기 (중복 허용)

각 자리가 1~n 범위를 **독립적으로, 중복 허용**하며 도는 형태

이전에 봤던 "조합(i<j<k)"과 결정적으로 다른 부분

```python
for i in range(1, n+1):
    cur_arr.append(i)
    for j in range(1, n+1):
        cur_arr.append(j)
        for k in range(1, n+1):
            cur_arr.append(k)
            # 조건 확인
            cur_arr.pop()
        cur_arr.pop()
    cur_arr.pop()
```

- 시간복잡도: O(N³)
- **핵심 차이점**: `range(1, n+1)`가 매번 **처음부터** 시작 → 같은 숫자가 여러 자리에 들어갈 수 있음 (예: i=2, j=2, k=2 가능)
- `cur_arr.append/pop`으로 **스택처럼** 현재 조합을 유지하는 것도 특징 (백트래킹의 초기 형태라고 볼 수 있음)

### 2. 팀 나누기 (사실은 "세자리 조합" 재활용)

```python
for i in range(len(abilities)):
    for j in range(i+1, len(abilities)):
        for k in range(j+1, len(abilities)):
            min_diff = min(min_diff, get_diff(i,j,k))
```

- 시간복잡도: O(N³)
- **포인트**: 문제 제목은 "팀 나누기"지만 본질은 "N명 중 3명을 뽑는 모든 조합"을 완전탐색하는 것. 자리별 독립선택(1번)과 헷갈리지 않게 구분해두면 좋아.
