# 코딩테스트

**완전탐색의 방법** : 다 해본다는 전략

- 중첩 for문 : 가장 직관적이지만 효율이 가장 낮음
- DFS : 한 길로 깊게 끝까지 가보고 돌아온다
- BFS : 가까운 단계부터 넓게 퍼져나간다
- 백트래킹 : DFS 하다가 가능성 없으면 중간에 끊는다

### 공통점

- 방문 처리
- 다음으로 갈 노드 확인
- 이동경로
  - dfs : 재귀호출 깊이
  - bfs : 큐로 주변노드 먼저

### DFS

인접 행렬 버전 템플릿

- for next_v in range() : dfs(next_v)
  - for 문돌다가 dfs만나면 dfs를 먼저 실행 → dfs 반복 호출로 깊게 들어감. depth

```jsx
n, m = map(int, input().split())

graph = [[0 for _ in range(n + 1)] for _ in range(n + 1)]

for _ in range(m):
    u, v = map(int, input().split())
    graph[u][v] = 1
    graph[v][u] = 1   # 무방향 그래프일 때

visited = [False for _ in range(n + 1)]

def dfs(vertex):
    visited[vertex] = True

    for next_v in range(1, n + 1):
        if graph[vertex][next_v] == 1 and not visited[next_v]:
            dfs(next_v)

dfs(1)
```

### BFS

```jsx
q.append(시작점)
visited[시작점] = True

while q:
    현재 = q.popleft()

    for 다음 in 현재와 연결된 후보들:
        if 아직 방문 안 했다면:
            visited[다음] = True
            q.append(다음)
```

## 투포인터

**투포인터**는 **구간을 직접 전부 다시 계산하지 않고, 왼쪽과 오른쪽 포인터를 움직이며 현재 구간 상태를 유지하는 방식**

1. 양쪽 끝에서 좁히는 투포인터

   ```jsx
   arr.sort()

   left = 0
   right = len(arr) - 1

   while left < right:
       total = arr[left] + arr[right]

       if total == target:
           print(left, right)
           break

       elif total < target:
           left += 1

       else:
           right -= 1
   ```

2. 연속부분 배열합

   ```jsx
   n, target = map(int, input().split())
   arr = list(map(int, input().split()))

   left = 0
   right = 0
   current_sum = 0
   answer = 0

   while True:
       if current_sum >= target:
           if current_sum == target:
               answer += 1

           current_sum -= arr[left]
           left += 1

       else:
           if right == n:
               break

           current_sum += arr[right]
           right += 1

   print(answer)
   ```

3. 연속부분 최소합

```jsx
n, s = map(int, input().split())
arr = list(map(int, input().split()))

left = 0
cur_sum = 0
answer = n + 1

for right in range(n):
    cur_sum += arr[right]

    while cur_sum >= s:
        answer = min(answer, right - left + 1)
        cur_sum -= arr[left]
        left += 1

print(0 if answer == n + 1 else answer)
```

1. 슬라이딩 윈도우

   ```jsx
   n, k = map(int, input().split())
   arr = list(map(int, input().split()))

   current_sum = sum(arr[:k])
   answer = current_sum

   for right in range(k, n):
       current_sum += arr[right]
       current_sum -= arr[right - k]

       answer = max(answer, current_sum)

   print(answer)
   ```
